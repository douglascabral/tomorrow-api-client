This patch updates macOS packaging. The release build now signs the complete app bundle with an ad hoc signature and verifies it again inside the mounted disk image before publication.

## Downloads

- **Windows x64:** `Tomorrow-1.0.2-windows-amd64.exe`
- **macOS Intel:** `Tomorrow-1.0.2-macos-amd64.dmg`
- **macOS Apple Silicon:** `Tomorrow-1.0.2-macos-arm64.dmg`
- **Linux x64:** `Tomorrow-1.0.2-linux-amd64.deb` for compatible Debian-based distributions

The macOS app has no Developer ID signature or Apple notarization. Gatekeeper may still block it.
