Tomorrow is an offline-first desktop API client. Workspace data stays on your device and is encrypted with a password you choose.

## Highlights

- Organize HTTP requests in collections and folders, and switch between environments.
- Build requests with authentication, headers, query parameters, and JSON, binary, or multipart bodies.
- Inspect responses and request history, generate code snippets, and run scripts before or after requests.
- Import Postman collections and environments, and export environments to Postman.
- Use the app in English or Brazilian Portuguese.

## Downloads

- **Windows x64:** `Tomorrow.exe`
- **macOS:** choose the Intel or Apple Silicon `.dmg`, then drag Tomorrow to Applications. The app is not signed with a Developer ID or notarized.
- **Linux x64:** install the `.deb` package on a compatible Debian-based distribution.
