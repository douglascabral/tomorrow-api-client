Release downloads now include the operating system and architecture in their names, making it easier to choose the right package.

## Downloads

- **Windows x64:** `Tomorrow-1.0.1-windows-amd64.exe`
- **macOS Intel:** `Tomorrow-1.0.1-macos-amd64.dmg`
- **macOS Apple Silicon:** `Tomorrow-1.0.1-macos-arm64.dmg`
- **Linux x64:** `Tomorrow-1.0.1-linux-amd64.deb` for compatible Debian-based distributions

On macOS, drag Tomorrow to Applications. The app is not signed with a Developer ID or notarized.
